# AltScreen tree in mib2q-carplay-rgi

This folder is the SD-card tree of **MHI2Q-CarPlay-AltScreen**
(<https://github.com/yuedizhibo/MHI2Q-CarPlay-AltScreen>, by yuedizhibo and Lanye-z) as run on
one MU1329 car, with local changes. It keeps its own licenses: `LICENSE` (PolyForm
Noncommercial 1.0.0) for the AltScreen material, `LICENSE.TOOLBOX-MIT` for MIB2 Toolbox,
`Toolbox/carplay_alt_screen/mirror_display/release/LICENSE.MMI-MIRROR` for the mirror runtime.
Noncommercial use only; do not resell.

Local changes on top of upstream:

- mirror sidecar rebuilt: 1:1 aspect (bottom crop), `logo.rgba` startup logo, transparent
  `watermark.rgba`; install/start/status/chain_test check both assets;
- `altscreen_boot_diag.sh` also captures `/tmp/carplay_hook.log`, the controller log and
  `cluster_geom.cfg`;
- route guidance: `Toolbox/scripts/rgi_companion.sh` (INSTALL installs the RGI hook, maneuver
  renderer and supervisor, rewires the carplay child, registers the iAP2 route-guidance IDs;
  RESTORE ORIGINAL removes them), listed in `RUNTIME_SCRIPTS`; STATUS reports the RGI state and
  the live dio_manager preloads;
- `Toolbox/scripts/cluster_layout*.sh` + four GEM entries "Cluster map layout: ..." write
  `/mnt/app/root/hooks/cluster_ui.url`, which the RGI Java sends to the cluster display as `showUI`;
- `Toolbox/scripts/cluster_shift*.sh` + two GEM entries "Cluster map shift: ..." write
  `/mnt/app/root/hooks/cluster_shift.cfg` (`small_dx=-476`, Sport test), which the RGI Java
  applies live to the video plane (displayable 3) on top of the stock small-stage offset;
- `Toolbox/scripts/cluster_area*.sh` + four GEM entries "Cluster map area: ..." write
  `/mnt/app/root/hooks/cluster_viewarea.cfg`; the RGI hook (now first in dio_manager's
  `LD_PRELOAD`) wraps AltScreen's `AirPlayReceiverSessionScreen_CopyDisplaysInfo` and rewrites
  the cluster display's view area / safe area from it;
- `Toolbox/scripts/dump_cluster_h264.sh` + GEM entry "Dump cluster video to SD (diagnostic)"
  copy the `/carplay111_h264` ring to `MMI-Cockpit-Carplay/logs/h264/`
  (analyse with `../tools/h264_ring_analyze.py`).

`universal/libcarplay_altscreen.so` and `mirror_display/release/carplay-alt111-mirror-display`
here are the unmodified upstream binaries. `../scripts/build_sd.sh` writes 30 fps patched
copies to the card (`../tools/patch_altscreen_fps.py`: the frame tap no longer skips every
second frame; the sidecar polls every 4 ms with a 16.7 ms minimum period instead of 20 ms /
33.3 ms) and updates the sidecar's `SHA256SUMS`; `ALTSCREEN_FULL_FPS=0` ships them as-is.

Generated by `../scripts/build_sd.sh`, never stored here: the HMI JAR
(`Toolbox/carplay_alt_screen/hmi/carplay_hook-basevideo3.jar`), the RGI payload
(`Toolbox/carplay_alt_screen/rgi/`), the `@CARPLAY_JAR_SIZE@` / `@CARPLAY_JAR_CKSUM@` values in
the three pinned scripts and `SHA256SUMS-SD.txt` (from `SHA256SUMS-SD.list`).
